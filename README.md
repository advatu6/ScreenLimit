# איי לומה

עולם וירטואלי בעברית: איים, משחקונים, שוק של דוכנים אמיתיים, אוהל ריפוי, הודעות פרטיות ואירועי חגים.

ב-repo הזה יש שני חלקים:

| תיקייה | מה יש בה |
|---|---|
| `world/` | העולם עצמו: קובץ אחד, `index.html`, עם כל הציור, המשחקים, השוק והחגים |
| `server/` | השרת: חשבונות, נוכחות בזמן אמת, מאגר נתונים עם הרשאות, והעלאת תמונות |

(הקובץ `ScreenLimit.zip` וה-workflow שב-`.github` שייכים לאפליקציה אחרת ולא קשורים לעולם.)

## הרצה במחשב

צריך Node.js בגרסה 20 ומעלה.

```bash
cd server
npm install
npm start
```

ואז פותחים בדפדפן את `http://localhost:3000`. **החשבון הראשון שנרשם הוא חשבון המנהלת.**

## הגדרות

הכול דרך משתני סביבה, ולכולם יש ברירת מחדל:

| משתנה | ברירת מחדל | מה הוא עושה |
|---|---|---|
| `PORT` | `3000` | הפורט שהשרת מאזין בו |
| `DATA_DIR` | `server/data` | איפה נשמרים מסד הנתונים והתמונות. **זו התיקייה שצריך לגבות** |
| `ADMIN_USERS` | ריק | שמות משתמש נוספים שיהיו מנהלים, מופרדים בפסיק |
| `TRUST_PROXY` | כבוי | לשים `1` כשהשרת רץ מאחורי פרוקסי של ספק אירוח, כדי שהגבלת הניסיונות תעבוד לפי כתובת אמיתית |
| `WORLD_FILE` | `world/index.html` | קובץ העולם שמוגש |

## מה השרת עושה

- **חשבונות:** הרשמה עם שם משתמש וסיסמה, בלי אימייל. קוד שחזור מוצג פעם אחת בהרשמה. סיסמאות, קודי שחזור ואסימוני כניסה נשמרים מגובבים בלבד.
- **זמן אמת:** כל מי שנמצא באותו אי רואה את האחרים, כולל צ'אט ותגובות. הצ'אט מסונן גם בשרת.
- **מאגר נתונים עם הרשאות:** השמירה של כל שחקן פרטית (גם מהמנהלת). דוכן נפתח רק אחרי אישור מנהלת. בקשות דוכן ודיווחים נראים רק לשולח ולמנהלת.
- **הודעות פרטיות:** מוצפנות מקצה לקצה בדפדפן. השרת מחזיק רק טקסט מוצפן.
- **תמונות:** רק PNG, JPEG, GIF ו-WebP, עד 5MB, נבדקות לפי התוכן ולא לפי הסיומת.
- **השעיה:** חשבון מושעה מנותק מיד ולא יכול להתחבר שוב עד שמבטלים.
- **התקנה כאפליקציה:** יש manifest, כך שאפשר "להוסיף למסך הבית" מהדפדפן בטלפון.

## בדיקות

```bash
cd server
npm test                    # 10 בדיקות של השרת: חשבונות, הרשאות, זמן אמת, העלאות, השעיה
node e2e/world-e2e.js       # בדיקה מקצה לקצה עם שני דפדפנים אמיתיים (דורשת Playwright)
```

הבדיקה מקצה לקצה רושמת שני אנשים, מכניסה אותם לעולם, ובודקת שהם רואים זה את זה, מתכתבים בצ'אט ובהודעה פרטית מוצפנת, שדוכן נפתח רק אחרי אישור, שאירוע חג נדלק לכולם, שההתקדמות נשמרת בחשבון, ושהשעיה והתנתקות עובדות.

## העלאה לאירוח

יש `server/Dockerfile` (בונים מתיקיית השורש: `docker build -f server/Dockerfile -t luma .`). הוא עוד לא נבדק בבנייה אמיתית.

מה שספק האירוח צריך לתת:

- הרצה של Node.js או של Docker
- **דיסק קבוע** שמחובר ל-`DATA_DIR`. בלי זה כל הנתונים נמחקים בכל עדכון
- תמיכה ב-WebSocket
- HTTPS. ההצפנה של ההודעות הפרטיות עובדת בדפדפן רק בכתובת מאובטחת (או ב-localhost)

## מה עוד לא נעשה

- **לא הועלה לשום מקום.** השרת רץ רק מקומית ובבדיקות.
- **אפליקציה לחנויות:** עוד אין עטיפה לאנדרואיד או לאייפון. בינתיים אפשר להתקין מהדפדפן.
- **פיצול לחדרים:** כל מי שבאותו אי נמצא יחד. כשיהיו הרבה אנשים באי אחד, צריך לפצל אותו לכמה עותקים.
- **גיבוי אוטומטי** של `DATA_DIR`.
- **מחיקת חשבון** מתוך העולם, והורדת המידע של המשתמש.
- **שרת אחד בלבד:** מסד הנתונים הוא קובץ SQLite, שמתאים לשרת יחיד. לעומס גדול מאוד צריך מסד נתונים נפרד.
- **בדיקה משפטית** של כללי העולם, תנאי השימוש וחוזה המוכרים. הם נוסחו בלי עורך דין.
